2. 네이티브 앱의 처리 항목과 목적

아래 정보는 사용자 Mac에서 처리됩니다. 파일명이나 경로에 개인의 이름 등이 포함될 수 있지만, 이를 처리한다는 사실이 개발자가 해당 정보를 외부에서 수집한다는 뜻은 아닙니다.

선택한 파일·폴더와 경로, 파일 시스템 정보
사용자가 선택한 폴더와 하위 항목의 이름·경로, 파일 식별 정보 및 시간 정보 등을 확인하여 한글 NFD 이름을 NFC 이름으로 변경하고, 변경 감지·충돌 방지·되돌리기 시 동일 파일 확인에 사용합니다. 이름 변환은 원본 파일의 내용 바이트를 변경하지 않습니다.
폴더 접근 북마크
감시 폴더와 ZIP 저장 위치의 경로 및 macOS 보안 범위 북마크를 로컬에 저장하여 사용자가 허용한 위치에 다시 접근합니다. 북마크는 파일 내용의 사본이 아니라 샌드박스 접근을 위한 권한 정보입니다.
앱 설정
알림 사용 여부·알림 간격·Dock 및 메뉴 막대 아이콘 표시 설정을 저장하여 사용 환경을 유지합니다. 로그인 시 실행 여부는 macOS의 로그인 항목 기능으로 관리됩니다. 알림은 macOS의 로컬 알림이며 원격 푸시 전송이 아닙니다.
변환 기록
변환 전후 이름·경로, 처리 시각, 파일 식별 정보 및 되돌림 상태 등을 저장하여 변환 기록 표시, Finder에서 찾기, 경로 복사와 개별 되돌리기를 제공합니다.
되돌린 이름의 재변환 제외 정보
되돌린 항목의 파일 식별 정보·이름·감시 폴더 연결 정보를 저장하여 같은 식별 정보와 이름이 유지되는 동안 다시 자동 변환하지 않도록 합니다.
ZIP 생성 시 파일 내용
사용자가 선택한 파일·폴더를 ZIP으로 만들 때에는 원본의 내용 바이트를 기기 안에서 읽어 새 ZIP에 넣습니다. ZIP 내부의 한글 NFD 이름을 NFC로 정리하며 원본 파일은 변경하지 않습니다. 기존 ZIP을 입력해도 그 안의 파일을 자동으로 풀어 변환하는 기능은 아닙니다. 이름만 바꾸는 감시 기능과 ZIP 생성을 위한 로컬 내용 읽기는 서로 다른 처리입니다.

네이티브 앱에는 계정·로그인, 파일 업로드, 사용자 정보의 자동 수집·전송, 분석·광고·추적 기능 또는 제3자 분석·광고 SDK가 없습니다. 네이티브 앱에 제3자 SDK를 통한 정보 수집도 없습니다. 앱의 샌드박스 권한에 네트워크 클라이언트 권한은 포함되어 있지 않습니다. 웹사이트 링크를 열면 외부 기본 브라우저로 이동하며, 그 이후의 방문은 아래 웹사이트 설명에 해당합니다.

3. 로컬 보관과 기록 한도

앱 설정, 감시 폴더 경로·북마크, ZIP 저장 위치 북마크, 변환 기록 및 재변환 제외 정보는 앱 샌드박스의 Application Support/NFD2NFC/state.json에 저장됩니다. 현재 앱의 전체 경로는 다음과 같습니다.

~/Library/Containers/com.pieroot.nfd2nfc/Data/Library/Application Support/NFD2NFC/state.json

  • 변환 기록은 최근 최대 1,000건을 유지하며, 한도를 넘으면 오래된 기록부터 제거합니다. 이는 건수 한도이지 1,000일 등 고정 보관기간이 아닙니다.
  • 설정과 북마크 등은 변경하거나 해당 상태를 삭제할 때까지 로컬에 남습니다. 재변환 제외 정보는 기록 한도와 별도로 관리되며, 해당 감시 폴더를 제거하거나 전체 상태를 초기화하면 그에 해당하는 제외 정보도 제거됩니다.
  • 감시 폴더를 제거해도 이미 남은 변환 기록 전체를 지우는 것은 아닙니다.
  • 생성한 ZIP은 기본적으로 ~/Documents/NFD2NFC/에 저장되며 사용자가 직접 삭제할 때까지 남습니다. 네이티브 ZIP에는 웹 변환기의 5분 만료 규칙이 적용되지 않습니다.

원본 파일·ZIP 출력물·사용자가 만든 백업은 앱 상태 파일과 별개입니다. 앱 삭제나 재설치가 샌드박스 상태, 파일 또는 백업의 자동 삭제를 보장하지 않습니다.

4. 감시 중단·권한 철회·초기화 및 삭제

감시 폴더 제거와 macOS 권한 철회는 다릅니다

앱의 실시간 감시 탭에서 해당 감시 폴더를 제거하면 그 폴더의 감시를 중단하고, 감시 목록의 경로·북마크 및 연결된 재변환 제외 정보를 제거하며 사용 중인 보안 범위 접근을 종료합니다. 원본 파일을 삭제하거나 이미 변환한 이름을 자동으로 되돌리지는 않습니다. 같은 폴더를 다시 추가하면 새 감시 항목으로 등록되므로 제거 전 변환 기록은 앱에서 되돌릴 수 없습니다.

감시 폴더 제거는 macOS에서 허용한 모든 접근 권한을 일괄 철회하는 기능이 아닙니다. ZIP 저장 위치의 별도 북마크나 변환 기록도 함께 모두 삭제되는 것은 아닙니다. 시스템 설정의 개인정보 보호 및 보안에서 앱에 대해 표시되는 파일 및 폴더 등 권한을 관리할 수 있으며, 표시되는 항목은 macOS 버전과 실제 허용한 권한에 따라 다릅니다. 저장된 앱 북마크를 포함하여 로컬 상태를 모두 없애려면 아래 초기화 방법을 사용하세요. 권한을 끄면 해당 위치를 감시하거나 ZIP을 저장하지 못할 수 있습니다.

로컬 상태 전체 초기화

현재 앱에는 변환 기록만 지우는 버튼이나 원격 삭제 기능이 없습니다. 설정·북마크·기록·제외 정보를 함께 초기화하려면 다음 순서로 진행하세요.

  1. 로그인 시 자동 실행도 중단하려면 먼저 일반 탭에서 로그인 시 실행을 끄세요. 이 설정은 macOS가 관리하므로 상태 파일 삭제만으로 해제된다고 가정하지 마세요.
  2. 앱 또는 메뉴 막대 메뉴에서 앱을 종료하세요. 창 닫기나 Dock·메뉴 막대 아이콘 숨기기는 종료가 아닙니다. 아이콘이 모두 숨겨져 있다면 응용 프로그램에서 앱을 다시 열어 종료할 수 있습니다.
  3. Finder의 이동 → 폴더로 이동…에서 ~/Library/Containers/com.pieroot.nfd2nfc/Data/Library/Application Support/NFD2NFC/를 여세요.
  4. 필요하면 state.json을 먼저 별도 위치에 백업한 뒤, 해당 폴더의 state.json을 삭제하세요. 휴지통에 옮긴 파일과 별도 백업에도 정보가 남을 수 있으므로, 필요 없어진 사본은 사용자가 따로 삭제해야 합니다.
  5. 앱을 다시 실행하면 저장된 설정·감시 목록·기록·제외 정보 없이 시작합니다. 사용할 폴더와 ZIP 저장 위치에 대한 접근을 다시 허용해야 합니다.

초기화는 변환한 파일명을 되돌리거나 원본·생성 ZIP을 삭제하지 않습니다. 되돌리기가 필요하다면 기록을 삭제하기 전에 가능한 항목을 개별적으로 되돌리세요. 제외 정보도 사라지므로 폴더를 다시 추가하면 이전에 되돌린 NFD 이름이 다시 변환될 수 있습니다. ZIP 파일은 Finder에서 별도로 삭제하세요. 개발자는 기기 안의 상태·원본·ZIP·백업을 원격으로 열람하거나 삭제할 수 없습니다.

5. 자발적 지원 문의

앱은 진단 자료를 자동으로 보내지 않습니다. 사용자가 이메일 또는 GitHub 이슈로 문의하면 개발자가 해당 채널에서 제공된 정보를 받게 됩니다. 문의는 선택 사항이며, 문의하지 않아도 네이티브 앱의 로컬 기능을 사용할 수 있습니다.

이메일 주소·발신자 표시명 등 연락 정보, GitHub 사용자명과 공개 프로필 정보, 문의 내용, 사용자가 자발적으로 첨부한 스크린샷·오류 메시지·진단 자료입니다. 자발적으로 공유한 자료에는 파일명·경로·macOS 및 앱 버전 등이 포함될 수 있습니다.
이용 목적
문의 답변, 문제 재현·원인 확인·수정, 문의 관련 후속 안내 및 개인정보 권리 요청의 처리를 위해 사용합니다. 문의 내용을 광고나 홍보 메시지 발송 목적으로 사용하지 않습니다.
보관과 삭제
문의 처리 및 필요한 후속 대응에 필요한 동안 보관하고, 목적을 달성하여 더 이상 필요하지 않은 개인정보는 삭제합니다. 고정된 일수의 자동 삭제 기능이나 일률적인 보관기간은 정하지 않습니다. 삭제 요청은 아래 이메일로 할 수 있으며, 개발자가 관리하는 문의 이메일·첨부파일·별도로 보관한 진단 자료 등 요청 범위의 정보를 확인하여 삭제하고 처리 결과를 안내합니다.

법령에 따른 보존 의무 등으로 요청을 전부 처리할 수 없는 경우에는 적용되는 이유와 범위를 안내합니다. 이 방침은 모든 문의에 특정 법정 보존기간이 적용된다고 정하지 않습니다. Gmail·GitHub가 자체적으로 보관하는 서비스 기록·백업이나 다른 사람이 복사한 공개 내용까지 개발자가 즉시 삭제할 수 있다는 보장은 없습니다.

6. 웹사이트·호스팅·광고

GitHub Pages 호스팅

이 웹사이트는 GitHub Pages를 통해 제공됩니다. 페이지·스타일·아이콘을 가져오는 요청에도 호스팅 제공자가 관여하며, GitHub는 IP 주소, 요청 시각, 브라우저·기기 정보 및 요청한 페이지 등 접속 정보를 자체 정책에 따라 처리할 수 있습니다. 정적 사이트라는 이유로 서버 접속 기록이 없거나 IP 주소가 전혀 처리되지 않는다고 보장하지 않습니다. 호스팅 기록의 구체적인 보관·삭제는 GitHub 정책과 절차에 따릅니다.

홈페이지 브라우저 변환기
