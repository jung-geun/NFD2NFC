빠른 시작

네이티브 macOS 앱의 탭은 실시간 감시 · 변환 기록 · 일반, 세 가지입니다.

  1. 실시간 감시에서 폴더 추가…를 누르고 감시할 실제 폴더를 선택해 접근을 허용하세요. 선택한 폴더 안의 기존 파일·폴더와 하위 폴더를 재귀적으로 확인하고, 이후 추가되거나 이동한 항목도 자동으로 처리합니다.
  2. 변환 기록에서 이름 변경 결과를 확인하세요. 각 항목의 Finder 위치 보기, 전체 경로 복사, 개별 이름 되돌리기를 사용할 수 있습니다. 최근 기록은 최대 1,000건 보관합니다.
  3. 일반에서 알림 사용 여부와 알림 간격, Dock·메뉴 막대 아이콘 표시, 로그인 시 자동 실행을 설정하세요.

감시와 ZIP 만들기는 다릅니다. 실시간 감시는 선택한 폴더 내부의 파일·폴더 이름을 NFC로 바꾸되 내용은 변경하지 않습니다. 원본 이름까지 유지한 채 전달용 파일을 만들려면 아래의 메뉴 막대 ZIP 기능을 사용하세요. 같은 이름의 다른 항목을 덮어쓰지 않습니다.

감시 목록에서 폴더를 제거하면 해당 폴더의 감시만 해제합니다. 원본 폴더나 파일을 삭제하거나, 이미 바뀐 이름을 일괄 복원하지 않습니다.

원본을 유지하는 ZIP 만들기

  1. 메뉴 막대의 NFD2NFC 아이콘을 클릭하세요. 파일 또는 폴더 선택…으로 항목을 고르거나, 파일·폴더를 팝오버에 드롭하세요.
  2. 최초 사용 시 저장 폴더 접근 요청에서 실제 사용자 홈의 Documents 또는 Documents/NFD2NFC를 선택하세요. 결과는 ~/Documents/NFD2NFC에 저장합니다. 앱 컨테이너의 가상 Documents나 임의의 다른 폴더를 선택해 대신 저장할 수는 없습니다.
  3. 완료 후 결과 ZIP이나 저장 폴더를 Finder에서 열어 확인하세요. 기본 결과 이름은 NFD2NFC.zip이며, 이미 존재하면 NFD2NFC (2).zip처럼 번호를 붙여 기존 파일을 보존합니다. ZIP 내부에서 NFC 이름이 겹치는 경우에도 (2) 등의 접미사를 붙입니다.

새 ZIP 내부의 한글 이름을 NFC로 정리하며, 원본 파일·폴더의 이름과 내용은 변경하지 않습니다. 기존 ZIP 파일을 선택해도 압축을 해제하거나 그 안의 이름을 고치는 기능은 아닙니다. 선택한 ZIP 파일 자체가 새 ZIP에 포함됩니다.

Finder로 결과를 압축 해제하면 macOS가 이름을 다시 NFD로 저장할 수 있습니다. 압축 해제 후의 표시와 별개로, 생성한 ZIP 내부의 한글 이름은 NFC입니다.

자주 묻는 질문과 문제 해결

감시 폴더를 추가했는데 이름이 바뀌지 않거나 기록이 없어요.

이미 NFC인 이름은 다시 변경하지 않으므로 새 변환 기록이 생기지 않을 수 있습니다. NFD와 NFC는 한글을 저장하는 방식의 차이라 Mac 화면에서는 똑같이 보일 수 있습니다. 눈에 보이는 글자 모양만으로 변환 여부를 판단하기는 어렵습니다.

실제로 이름이 바뀐 항목은 변환 기록에서 확인하세요. 이전에 개별 되돌리기를 한 항목은 같은 파일 식별자와 같은 이름을 유지하는 동안 자동 재변환에서 제외됩니다.

선택한 폴더 자체나 숨김 파일도 이름이 바뀌나요?

실시간 감시는 선택한 최상위 폴더 자체의 이름을 유지하고 그 안을 탐색합니다. 다른 감시 폴더에 접근하는 데 필요한 상위 경로도 보호합니다. 이름이 마침표(.)로 시작하는 숨김 항목과 그 안의 항목, 심볼릭 링크는 실시간 변환에서 제외합니다. 이름이 마침표로 시작하지 않는 항목은 Finder에서 숨김 속성이 지정되어 있어도 변환 대상입니다.

이 설명은 실시간 감시 범위에 관한 것입니다. 메뉴 막대 ZIP 기능은 숨김 파일과 빈 디렉토리를 보존하는 별도의 처리 방식입니다.

접근 권한 오류가 나거나 외장 디스크의 감시가 멈췄어요.

외장 디스크가 연결되어 있고 해당 폴더가 Finder에서 열리는지 먼저 확인하세요. 이동·삭제된 폴더이거나 저장된 접근 권한이 더 이상 유효하지 않으면 오류가 표시될 수 있습니다.

감시를 제거하지 말고 실시간 감시의 폴더 추가…를 눌러 같은 위치의 실제 폴더를 다시 선택해 접근 권한을 갱신하세요. 기존 감시 항목을 유지하므로 이전 변환 기록의 되돌리기와 재변환 제외 정보도 계속 사용할 수 있습니다. 감시를 제거한 뒤 다시 추가하면 새 감시 항목으로 등록되어 이전 기록을 되돌릴 수 없고 재변환 제외 정보도 사라집니다. 감시 제거는 파일 삭제가 아닙니다. 이름 변경이나 ZIP 저장 중 디스크 오류가 난 경우에는 디스크 연결, 쓰기 권한과 여유 공간도 확인하세요. 오류가 계속되면 표시된 오류 문구를 익명화해 문의해주세요.

이름 되돌리기가 실패해요. 한 번에 모두 되돌릴 수 있나요?

되돌리기는 변환 기록의 항목별 기능이며 일괄 되돌리기는 제공하지 않습니다. 파일 식별 정보가 없거나, 파일이 이동·교체되었거나, 해당 감시 폴더의 권한이 없어지면 안전하게 되돌릴 수 없습니다.

앱은 기록의 파일 식별 정보와 현재 항목이 일치하는지 확인합니다. 확인에 실패하면 다른 파일을 덮어쓰거나 강제로 이름을 바꾸지 않습니다. 원래 이름을 다른 항목이 사용 중인 경우에도 덮어쓰지 않습니다. Finder에서 대상과 위치를 확인하고, 감시 폴더 권한 문제라면 감시를 제거하지 말고 폴더 추가…에서 같은 폴더를 다시 선택하세요. 감시를 제거했다가 다시 추가한 폴더의 이전 기록은 되돌릴 수 없습니다.

ZIP 저장 권한 요청을 취소했거나 ZIP이 만들어지지 않았어요.

저장 권한 요청을 취소하면 생성 결과가 생기지 않습니다. 다시 파일·폴더를 선택하고, 권한 요청에서 실제 Documents 또는 Documents/NFD2NFC를 선택하세요. 결과 저장 위치는 ~/Documents/NFD2NFC로 고정되어 있습니다.

저장 폴더의 쓰기 권한과 디스크 여유 공간을 확인하세요. ZIP 생성이 실패하거나 취소되면 완성된 새 결과를 제공하지 않으며 미완성 ZIP은 정리합니다. 이미 있던 ZIP과 원본은 변경하지 않습니다. 심볼릭 링크 등 지원하지 않는 입력으로 오류가 난 경우에는 오류 문구를 확인하고 해당 입력을 제외한 뒤 다시 시도하세요.

창을 닫았는데 계속 실행돼요. 아이콘을 모두 숨겼다면 어떻게 다시 여나요?

창 닫기는 앱 종료가 아닙니다. 창을 닫거나 일반에서 Dock과 메뉴 막대 아이콘을 모두 숨겨도 백그라운드 감시는 계속됩니다.

Finder의 응용 프로그램(Applications)에서 NFD2NFC를 다시 열면 실행 중인 앱의 창이 다시 나타납니다. 아이콘 표시 설정도 여기서 되돌릴 수 있습니다. 감시를 완전히 중단하려면 앱 메뉴의 NFD2NFC 종료 또는 메뉴 막대 팝오버의 종료 항목을 사용하세요.

알림이 안 오거나 로그인 후 앱이 실행되지 않아요.

일반의 알림 설정과 macOS 시스템 설정의 알림에서 앱의 알림 허용 여부를 확인하세요. 알림 간격은 기본 30초, 최소 1초입니다. 이 값은 알림을 모아 전달하는 간격이며 폴더 감시의 실행 주기를 뜻하지 않습니다.

로그인 시 자동 실행은 macOS의 로그인 항목 승인이 필요할 수 있습니다. 앱의 안내에 따라 시스템 설정에서 승인 상태를 확인하세요. 이 기능은 로그인할 때 앱을 실행하는 것이며, 직접 종료한 앱을 즉시 다시 실행하는 기능은 아닙니다.

이전 앱에서 3.0 네이티브 앱으로 옮긴 뒤 감시 폴더가 없어요.

3.0에서 Electron 기반 앱을 네이티브 macOS 앱으로 전환했습니다. App Sandbox의 접근 권한 때문에 이전 앱에서 감시하던 폴더를 그대로 사용할 수 없습니다. 실시간 감시 → 폴더 추가…에서 각 폴더를 다시 선택해 접근 권한을 허용하세요.

웹의 100MiB·5분 제한과 광고가 macOS 앱에도 적용되나요?

아닙니다. 100MiB 크기 제한과 변환 결과의 5분 만료는 별도 웹 변환기에만 적용됩니다. 네이티브 macOS 앱에는 이 제한이 적용되지 않으며, 처리 가능한 양은 디스크 공간 등 기기 환경에 영향을 받습니다. 앱이 만든 ZIP은 사용자가 직접 삭제하기 전까지 저장 위치에 남습니다.

네이티브 앱에는 광고나 분석 SDK가 없으며 파일을 서버로 업로드하지 않습니다. 별도 웹 변환기 홈페이지에는 Google AdSense 광고가 있으며 외부 광고 서비스의 데이터 처리가 발생할 수 있습니다. 이 지원 페이지에는 광고와 스크립트가 없습니다. 자세한 구분은 개인정보 처리방침에서 확인하세요.

개인정보와 로컬 데이터 초기화

네이티브 앱은 설정, 선택한 폴더 경로와 접근 권한 정보, 변환 기록, 되돌린 항목의 자동 재변환 제외 정보를 로컬에 저장합니다. 계정이나 원격 데이터 삭제 기능은 없습니다. 지원 채널과 웹사이트의 데이터 처리는 개인정보 처리방침을 참고하세요.

초기화는 이름 되돌리기가 아닙니다. 저장 상태를 제거하면 기존 변환 기록을 통한 되돌리기를 사용할 수 없게 되고, 감시 폴더와 권한·설정을 다시 지정해야 합니다. 제외 정보도 사라지므로, 나중에 폴더를 다시 추가하면 되돌렸던 이름이 다시 변환될 수 있습니다. 폴더 권한 문제만 있다면 먼저 같은 폴더 다시 선택을 시도하세요.

로컬 상태를 수동으로 초기화하려면 아래 순서를 따르세요. 자동 삭제 명령은 제공하지 않습니다.

  1. 창만 닫지 말고 앱 메뉴나 메뉴 막대에서 NFD2NFC를 완전히 종료하세요. 아이콘을 모두 숨겼다면 응용 프로그램에서 앱을 다시 열어 종료하세요.
  2. Finder의 이동 → 폴더로 이동…에서 ~/Library/Containers/com.pieroot.nfd2nfc/Data/Library/Application Support/NFD2NFC/를 여세요.
  3. state.json을 다른 안전한 위치에 먼저 복사해 백업하세요. 백업에도 경로와 변환 기록 등 개인정보가 포함될 수 있으니 외부에 공유하지 마세요.
  4. 백업을 확인한 뒤 해당 폴더의 state.json만 Finder에서 휴지통으로 옮기세요. 컨테이너 전체나 다른 파일을 지울 필요는 없습니다. 파일이 없다면 임의로 다른 위치의 파일을 삭제하지 마세요.
  5. 앱을 다시 실행하고 필요한 감시 폴더를 선택해 권한과 설정을 다시 지정하세요.

원본 파일·폴더와 이미 생성한 ZIP은 이 초기화로 삭제되지 않습니다. 기존 이름 변경도 그대로 유지됩니다. 만들어 둔 ZIP이 필요 없으면 저장 위치에서 직접 확인한 뒤 별도로 삭제하세요. 앱 제거만으로 로컬 상태가 자동 삭제된다고 가정하지 마세요.

문의 전 확인할 정보

아래 정보만으로 시작해 주세요. 파일 내용이나 실제 전체 경로를 보내지 않아도 됩니다.

  • 앱 버전: 앱 창을 연 뒤 화면 상단 앱 메뉴에서 NFD2NFC에 관하여를 선택하면 정보 패널에서 확인할 수 있습니다.
  • macOS 버전: Apple 메뉴의 이 Mac에 관하여에서 확인하세요.
  • 재현 순서: 사용한 탭 또는 메뉴 막대 기능, 수행한 동작, 기대한 결과와 실제 결과를 간단히 적어주세요.
